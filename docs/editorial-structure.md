# 편집 구조

이 가이드는 한 개의 본문을 웹과 LaTeX로 각각 옮깁니다. 네 개의 장 파일에는 `## 번호. 제목` 형식의 항목이 앞의 세 장에 22개씩, 네 번째 장에 17개 있습니다. 각 항목은 `chapter/page` ID로 이미지 하나와 연결됩니다. `content/deep-dives.md`의 상세 해설과 `content/questions-cases.md`의 추가 설명은 83개 ID를 빠짐없이 보강하고, `content/supplements.md`의 심화 항목은 같은 ID에 연결됩니다.

`tools/build.py`는 모든 ID, 순서, 이미지 대응을 검사한 후 `data.json`과 `guide.tex`를 만듭니다. `tools/site_builder.py`는 같은 데이터를 이용해 목차형 `index.html`과 장별 `lecture/01.html`~`04.html`을 생성합니다. 해설을 수정한 뒤에는 생성 파일을 수동으로 고치지 않고 빌더를 다시 실행합니다. 웹 화면에서 인라인·디스플레이 수식은 MathJax가 표시하며, LaTeX 문서는 같은 수식 표현을 사용합니다.

각 슬라이드는 세 층으로 읽힙니다. 장별 본문은 정의·가정·핵심 유도·경제학적 해석을 순서대로 제시합니다. `deep-dives.md`는 본문을 되풀이하는 대신 다른 유도법, 성립 조건, 적용의 함의를 더합니다. `questions-cases.md`는 새로운 수치나 상황에 개념을 적용합니다. 웹에서는 뒤의 두 층을 각자의 제목으로 펼쳐 읽고, PDF에서는 제목을 붙여 본문 뒤에 배치합니다. 같은 숫자와 결론을 여러 층에 반복하지 않도록 편집합니다.

이미지는 1600×1200픽셀 WebP로 변환되어 슬라이드별로 제공됩니다. 원본 PDF, 녹취 텍스트, 판서 사진은 이 저장소의 배포 파일이 아닙니다. `.gitignore`와 `tools/check.py`가 원본 파일 형식과 슬라이드 대응을 확인합니다.

페이지의 문장은 모형의 가정, 단위, 부호를 먼저 정의하고 계산 뒤에 직관과 적용의 한계를 놓는 순서로 썼습니다. 역사적 그래프의 숫자는 현재의 예상 수익률로 해석하지 않고, 계산 예시는 소수 단위로 검산합니다.
