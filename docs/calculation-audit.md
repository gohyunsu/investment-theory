# 계산 검증 기록

## 정규분포의 2.5% 수익률 분위수

$\mu=10\%$, $\sigma=15\%$, $z_{.025}\simeq-1.96$이면 $q_{.025}=.10-1.96(.15)=-.194$다. 왼쪽 수익률 임계값은 -19.4%, 양의 손실 VaR는 19.4%다. -23%는 이 입력과 일치하지 않는다.

## 모집단 분산과 표본분산

상태확률 $(.1,.2,.4,.2,.1)$과 수익률 $(-.05,.05,.15,.25,.35)$의 모집단 평균은 $.15$, 분산은 $.012$다. 다섯 수익률을 각 한 번 관측한 독립 표본으로 간주하면 표본평균은 $.15$, 표본분산은 $(.04+.01+0+.01+.04)/4=.025$다. 두 분산은 확률가중과 추정 문제의 차이 때문에 다른 값을 가진다.

## 두 위험자산 최소분산

$\sigma_1=.15$, $\sigma_2=.20$, $\rho=.20$이면 공분산은 $.006$이다. $A=.15^2+.20^2-2(.006)=.0505$, $w_1=(.20^2-.006)/A=.6732673$, $w_2=.3267327$이다. 최소분산은 약 $.0171089$, 표준편차는 약 13.080%다. 분모에 $.14^2$나 둘째 자산의 표준편차 $.22$를 대입하면 같은 결과를 얻을 수 없다.

## 접점 포트폴리오

무위험 수익률 5%, 평균 $(.10,.14)$, 공분산행렬 $\begin{pmatrix}.0225&.006\\.006&.04\end{pmatrix}$에서 접점 비중은 $(.45839874,.54160126)$이다. 기대수익 $.12166405$, 표준편차 $.13942891$, 샤프비율 약 $.51398272$이다. `.5416`은 둘째 자산 비중과 일치하며 샤프비율과는 다르다.

## 그래프와 단위

샤프비율은 같은 기간의 초과수익과 표준편차로 계산한다. 분산은 수익률 단위의 제곱, 표준편차는 수익률과 같은 단위다. 분산을 가로축으로 한 기회집합과 표준편차를 가로축으로 한 기회집합의 모양은 달라진다. 직선 자본배분선의 수식은 위험자산 비중이 음수가 아닐 때 $\sigma=w\sigma_P$로 쓸 수 있고, 일반적으로는 $\sigma=|w|\sigma_P$다.
